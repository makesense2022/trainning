## 🎯 项目列表

### 项目 1：个人知识库RAG系统 🔥

**难度**：🔴 中等  
**时间**：4-6小时  
**技能**：Python + LangChain + RAG + 向量数据库

**功能需求**：
- [ ] 支持上传PDF/Markdown/TXT文件
- [ ] 智能文档切分和向量化
- [ ] 语义搜索和问答
- [ ] 显示引用来源
- [ ] 对话历史记忆
- [ ] 支持多文档跨文档检索

**技术栈**：
```
Backend:
- LangChain: RAG链构建
- ChromaDB: 向量存储
- FastAPI: Web API
- OpenAI/DeepSeek: LLM

Frontend (可选):
- Streamlit (快速原型)
- 或 React + Ant Design (完整UI)
```

**评分标准**：
- 基础功能（60分）：上传文档、问答、显示来源
- 进阶功能（30分）：对话历史、多文档检索、chunk可视化
- 代码质量（10分）：结构清晰、有测试、有文档

**面试加分点**：
- 实现文档切分策略对比
- 加入评测指标（RAGAS）
- 优化检索性能（MMR、重排序）
- 成本统计（Token使用）

### 项目 2：多工具AI Agent 🔥🔥

**难度**：🔥 挑战  
**时间**：6-8小时  
**技能**：Agent + 工具开发 + ReAct + API集成

**功能需求**：
- [ ] 至少集成3个工具：
  - 🔍 搜索工具（调用搜索API）
  - 🌤️ 天气工具（天气API）
  - 🧮 计算器（Python eval）
  - 📚 知识库工具（项目1的RAG）
- [ ] ReAct思维链可视化
- [ ] 多轮对话支持
- [ ] 错误处理和兜底
- [ ] 工具调用统计

**技术栈**：
```
Core:
- LangChain Agent
- Custom Tools
- OpenAI Function Calling

API集成:
- SerpAPI/Tavily (搜索)
- OpenWeatherMap (天气)

可视化:
- LangSmith (追踪)
- Streamlit (展示)
```

**挑战任务**：
设计一个能完成复杂多步任务的Agent：

```
用户: "帮我查一下北京明天的天气，如果温度低于10度，
      从我的知识库里找一下保暖装备推荐"

Agent思维过程:
1. [Thought] 需要查天气
2. [Action] get_weather("北京", "明天")
3. [Observation] 5°C
4. [Thought] 低于10度了，需要查知识库
5. [Action] search_knowledge("保暖装备")
6. [Observation] 找到3篇文档...
7. [Thought] 可以综合回答了
8. [Final Answer] 明天北京5°C...建议...
```

**评分标准**：
- 工具实现（40分）：至少3个工具，功能正常
- Agent逻辑（30分）：能正确选择和组合工具
- 用户体验（20分）：思维过程清晰、错误处理好
- 创新性（10分）：独特的工具或应用场景

**面试加分点**：
- 实现工具的异步调用
- 加入人工审批（Human-in-the-Loop）
- 实现多Agent协作（如计划者+执行者）
- 使用LangGraph重构

## 📝 项目开发流程

### 1. 需求分析（10%）
```markdown

作为一个[角色]，我想要[功能]，以便[价值]

## 功能列表
- [ ] 必须有（MVP）
- [ ] 应该有（重要但非紧急）
- [ ] 可以有（锦上添花）

## 技术限制
- 预算：API调用成本
- 时间：开发周期
- 技能：现有技术栈
```

### 2. 设计（20%）
```markdown
## 系统架构
[画出架构图]

## 数据模型
User, Document, Conversation, Message...

## API设计
GET  /api/documents
POST /api/chat
...

## UI原型
[手绘或Figma]
```

### 3. 开发（50%）

**迭代开发**：
```
Week 1: MVP
- 核心功能跑通
- 不考虑UI
- 不考虑性能

Week 2: 完善
- 加入错误处理
- 优化体验
- 添加测试

Week 3: 打磨
- UI美化
- 性能优化
- 文档完善
```

### 4. 测试（10%）
```python
# 单元测试
pytest tests/

# 集成测试
pytest tests/integration/

# E2E测试（可选）
playwright test
```

### 5. 部署（10%）
```bash
# Docker部署
docker-compose up -d

# 或Vercel部署（前端）
vercel deploy

# 或Railway部署（后端）
railway up
```
